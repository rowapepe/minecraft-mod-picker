# Minecraft Mod Picker — интерфейс и поведение

## 1. Назначение документа

Документ описывает экраны приложения и связанные с ними состояния.

Этот файл отвечает на вопросы:

- какие экраны есть и как человек между ними попадает;
- какие блоки есть на экране;
- какие данные и действия доступны в каждом блоке;
- какие состояния экрана должен учитывать интерфейс;
- какие проверки выполняются до отправки запроса.

Сценарии поведения описаны в `02-users-and-scenarios.md`, точные правила — в `05-rules-and-data-meaning.md`.

## 2. Общая структура

Интерфейс состоит из трёх экранов в браузере. Вход в систему обязателен. Свободной навигации между экранами нет: какой экран открыть, определяет роль учётной записи (раздел 9).

| Экран        | Кому доступен      | Описание    |
| ------------ | ------------------ | ----------- |
| Вход         | всем, кто не вошёл | раздел 7    |
| Админ-панель | администратору     | раздел 8    |
| Экран поиска | пользователю       | разделы 3–6 |

Блоки экрана поиска сверху вниз:

1. Заголовок и пояснение, кнопка «Выйти».
2. Форма запроса: поле ввода, счётчик символов, кнопка поиска.
3. Примеры запросов.
4. Область результатов: сообщение о состоянии, ответ с объяснением, карточки модов.

## 3. Экран поиска

Доступен только пользователю после входа (`RULE-AUTH-05`).

### 3.1. Заголовок и пояснение

Название приложения «Minecraft Mod Picker» и одна строка пояснения: «Опишите, что вы хотите сделать в игре, и мы подберём подходящие моды».

В правой части заголовка — кнопка «Выйти» (`GWT-20`).

### 3.2. Форма запроса

Поле ввода:

- многострочное текстовое поле с подсказкой-примером («Например: хочу автоматизировать ферму и не получить лагов»);
- максимальная длина — по `RULE-UI-02`;
- под полем счётчик введённых символов.

Кнопка «Найти моды»:

- запускает поиск;
- во время поиска недоступна;
- поиск также запускается сочетанием Ctrl+Enter (Cmd+Enter на macOS).

Сообщение о валидации показывается под полем (раздел 6).

### 3.3. Примеры запросов

Несколько готовых формулировок в виде кнопок под формой, например:

- «Хочу автоматизировать ферму и не получить лагов»
- «Нужен мод, чтобы удобно хранить много предметов»
- «Хочу улучшить производительность на слабом компьютере»
- «Ищу мод с новой генерацией мира и приключениями»

При выборе примера текст подставляется в поле и поиск запускается сразу (`GWT-05`).

### 3.4. Область результатов

Показывается после запуска поиска. Состоит из двух частей:

- блок ответа с объяснением (над карточками);
- список карточек модов, упорядоченный по релевантности.

### 3.5. Карточка мода

Карточка содержит:

- название мода;
- короткое описание;
- категории (до пяти меток);
- ссылку «Открыть на Modrinth».

Оценка BM25 пользователю не показывается. Ссылка открывает страницу мода в новой вкладке (`GWT-07`, `RULE-UI-04`).

## 4. Состояния экрана поиска

| Состояние                 | Что видит игрок                                                                    |
| ------------------------- | ---------------------------------------------------------------------------------- |
| Начальное                 | Заголовок, пустая форма, примеры запросов, области результатов нет                 |
| Ошибка ввода              | Сообщение под полем, область результатов не меняется                               |
| Загрузка                  | Кнопка поиска недоступна, в области результатов индикатор «Ищем подходящие моды…»  |
| Результаты                | Блок ответа и карточки модов                                                       |
| Результаты без объяснения | Карточки модов и сообщение, что объяснение недоступно                              |
| Нет результатов           | Сообщение «Подходящих модов не найдено. Попробуйте описать задачу другими словами» |
| Ошибка поиска             | Сообщение «Не удалось выполнить поиск. Попробуйте ещё раз», карточек нет           |

## 5. Действия и переходы на экране поиска

| Действие                                   | Результат                                                              |
| ------------------------------------------ | ---------------------------------------------------------------------- |
| Ввод текста                                | Обновляется счётчик символов, сообщение об ошибке ввода скрывается     |
| Нажатие «Найти моды» с корректным запросом | Состояние «Загрузка», затем «Результаты» или другое итоговое состояние |
| Нажатие «Найти моды» с пустым запросом     | Состояние «Ошибка ввода»                                               |
| Выбор примера запроса                      | Текст подставляется в поле, запускается поиск                          |
| Нажатие «Открыть на Modrinth»              | Страница мода открывается в новой вкладке                              |
| Повторный поиск                            | Предыдущие результаты заменяются новыми                                |

## 6. Валидации на экране поиска

| Условие                             | Реакция                                                                |
| ----------------------------------- | ---------------------------------------------------------------------- |
| Поле пустое или состоит из пробелов | Сообщение «Опишите задачу, чтобы начать поиск», запрос не отправляется |
| Длина запроса больше допустимой     | Поле не принимает лишние символы, счётчик показывает предел            |

Остальные проверки (например, доступность сервисов) выполняются вне интерфейса и приводят к состояниям из раздела 4.

## 7. Экран входа

Первый экран приложения. Доступен всем, кто не вошёл.

### 7.1. Блоки

Сверху вниз:

1. Название приложения «Minecraft Mod Picker».
2. Форма входа: поле «Логин», поле «Пароль» (вводимые символы скрыты), кнопка «Войти».
3. Место для сообщения об ошибке под формой.

На экране нет ссылок и кнопок регистрации, создания учётной записи и восстановления пароля (`RULE-AUTH-01`, `GWT-23`).

Вход запускается кнопкой «Войти» или клавишей Enter в одном из полей.

### 7.2. Состояния

| Состояние       | Что видит человек                                                                       |
| --------------- | --------------------------------------------------------------------------------------- |
| Начальное       | Пустая форма, сообщения нет                                                             |
| Ошибка ввода    | Сообщение «Введите логин и пароль», данные не проверяются                               |
| Проверка        | Кнопка «Войти» недоступна, пока идёт проверка                                           |
| Неверные данные | Сообщение «Неверный логин или пароль», поле пароля очищено, поле логина сохраняет текст |

### 7.3. Действия

| Действие                             | Результат                              |
| ------------------------------------ | -------------------------------------- |
| Ввод текста в поле                   | Сообщение об ошибке скрывается         |
| «Войти» с пустым логином или паролем | Состояние «Ошибка ввода» (`GWT-17`)    |
| «Войти» с данными пользователя       | Экран поиска (`GWT-14`)                |
| «Войти» с данными администратора     | Админ-панель (`GWT-15`)                |
| «Войти» с неверными данными          | Состояние «Неверные данные» (`GWT-16`) |

## 8. Админ-панель

Доступна только администратору после входа (`RULE-AUTH-05`).

### 8.1. Блоки

Сверху вниз:

1. Заголовок «Админ-панель» и кнопка «Выйти» (`GWT-20`).
2. Числовые показатели (`RULE-ADM-01`). Сейчас один показатель: «Поисковых запросов пользователя» с одним числом.

Набор показателей может расширяться (GAP-12): новые показатели добавляются в этот блок.

### 8.2. Состояния

| Состояние           | Что видит администратор                                                         |
| ------------------- | ------------------------------------------------------------------------------- |
| Загрузка            | Вместо чисел индикатор «Загружаем данные…»                                      |
| Показатели показаны | Числовые показатели; для числа запросов — 0, если запросов не было              |
| Ошибка загрузки     | Сообщение «Не удалось получить данные. Попробуйте обновить страницу», чисел нет |

Показатели загружаются при открытии панели. Новые значения администратор получает, обновив страницу (`GWT-22`).

## 9. Навигация и доступ

| Ситуация                                        | Что показывается        |
| ----------------------------------------------- | ----------------------- |
| Вход не выполнен, открыт любой адрес приложения | Экран входа (`GWT-18`)  |
| Вход пользователя                               | Экран поиска (`GWT-14`) |
| Вход администратора                             | Админ-панель (`GWT-15`) |
| Пользователь открывает адрес админ-панели       | Экран поиска (`GWT-19`) |
| Администратор открывает адрес экрана поиска     | Админ-панель (`GWT-19`) |
| «Выйти» на любом экране                         | Экран входа (`GWT-20`)  |

Правила: `RULE-AUTH-04`, `RULE-AUTH-05`, `RULE-AUTH-06`.
