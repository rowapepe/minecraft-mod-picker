# Product — индекс

## Назначение

Этот файл — точка входа в продуктовую документацию проекта.

Minecraft Mod Picker — веб-приложение, которое подбирает моды Minecraft под задачу игрока: ищет по описаниям модов с Modrinth собственным поиском BM25 и объясняет выбор с помощью LLM.

Документация разделена так, чтобы:

- человеку было удобно понять смысл продукта, пользовательский путь и интерфейс;
- разработчику было удобно найти требование к конкретному экрану или правилу;
- кодинговый агент мог отделить контекст от проверяемого поведения и точных правил.

## Актуальные документы

| Файл | Назначение |
|---|---|
| `01-context.md` | Главный человекочитаемый документ: цель, границы первой версии, ограничения, общая логика |
| `02-users-and-scenarios.md` | Роли и сценарии поведения в формате Given/When/Then (`GWT-NN`) |
| `03-requirements.md` | Требования (`REQ-NN`) и способ проверки каждого из них |
| `04-interface-and-behavior.md` | Экраны, блоки, состояния, действия, валидации, оформление и талисман |
| `05-rules-and-data-meaning.md` | Смысл данных и источников, пронумерованные правила (`RULE-ГРУППА-NN`) |

## Как читать

- Чтобы понять продукт — `01-context.md`.
- Чтобы собрать или проверить интерфейс — `04-interface-and-behavior.md`, затем `02-users-and-scenarios.md`.
- Чтобы понять, что именно проверяется на контрольных точках — `03-requirements.md`.
- Чтобы реализовать поиск и ответ — `05-rules-and-data-meaning.md`, затем `../Tech/`.
- Открытые вопросы (`GAP-NN`) и принятые решения — `../Service/decisions.md`.
