# 04. API и доступ

Статус: черновик контракта. Контракт между интерфейсом и бэкендом согласуют Прощаев Алексей и Верзаков Никита. Интерфейс написан по этому контракту, заглушка API (`../../code/frontend/dev-stub`) его повторяет.

Все методы работают с JSON, адрес начинается с `/api`. Сессия передаётся в cookie `session` (подписана, `HttpOnly`).

## Методы

| Метод и адрес           | Кому доступен  | Вход                              | Успешный ответ                                            | Ошибки                                                             |
| ----------------------- | -------------- | --------------------------------- | --------------------------------------------------------- | ------------------------------------------------------------------ |
| `POST /api/auth/login`  | всем           | `{ "login": "", "password": "" }` | `200 { "role": "user" \| "admin" }`, устанавливает cookie | `401` — неверные данные                                            |
| `POST /api/auth/logout` | вошедшим       | —                                 | `204`, cookie сбрасывается                                | —                                                                  |
| `GET /api/auth/me`      | всем           | —                                 | `200 { "role": "user" \| "admin" }`                       | `401` — вход не выполнен                                           |
| `POST /api/search`      | только `user`  | `{ "query": "" }`                 | `200 { "mods": [Mod], "answer": string \| null }`         | `400` — пусто или длиннее 500; `401`; `403`; `500` — ошибка поиска |
| `GET /api/admin/stats`  | только `admin` | —                                 | `200 { "requests": number }`                              | `401`; `403`                                                       |

`Mod`: `{ "slug": string, "title": string, "description": string, "categories": string[], "url": string }`. Оценка BM25 наружу не отдаётся.

Правила методов:

- `/api/search` увеличивает счётчик на 1, если запрос прошёл проверки длины и пустоты, независимо от исхода (`RULE-ADM-02`); запрос с ответом `400` счётчик не меняет.
- `answer: null` при непустом `mods` означает, что LLM недоступна: интерфейс показывает «Объяснение сейчас недоступно, но вот найденные моды» (`RULE-ANS-04`, `GWT-09`).
- Пустой `mods` означает «ничего не найдено» (`GWT-06`).
- При ошибке `500` тело содержит только короткое сообщение без технических деталей (`RULE-ERR-01`).
- Все методы кроме `login` и `me` при отсутствии сессии отвечают `401`; при чужой роли — `403`. Интерфейс по ответу `me` переадресует на экран своей роли (`GWT-18`, `GWT-19`).
- Неверный логин и неверный пароль дают один и тот же ответ `401` (`RULE-AUTH-03`).

## Внешние сервисы

- Modrinth API: только при выгрузке корпуса, в работе приложения не используется.
- LLM API: ключ в `.env`.

## Доступ

Две фиксированные учётные записи, данные берутся из `.env` (`RULE-AUTH-01`, `RULE-AUTH-02`, GAP-09). Срок жизни сессии не ограничен, пока человек не нажмёт «Выйти» или не закроет браузер (GAP-11): cookie без `Max-Age`.
