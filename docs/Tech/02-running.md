# 02. Запуск и настройки

Статус: интерфейс запускается, бэкенд — заготовка.

## Требования

- Node.js 20 и новее, npm — для интерфейса (`code/frontend`).
- Python 3.12 и новее, `uv` — для бэкенда (`code/backend`, пока пусто).

## Настройки

Все настройки проекта лежат в одном файле `.env` в корне репозитория. Его читают интерфейс (заглушка API и прокси), бэкенд и скрипты. Шаблон — `.env.example` (имена без значений). Файл `.env` в Git не попадает.

| Переменная                      | Для чего                                                                                                       | Кто читает             |
| ------------------------------- | -------------------------------------------------------------------------------------------------------------- | ---------------------- |
| `USER_LOGIN`, `USER_PASSWORD`   | Учётная запись пользователя (`RULE-AUTH-02`)                                                                   | бэкенд, заглушка API   |
| `ADMIN_LOGIN`, `ADMIN_PASSWORD` | Учётная запись администратора                                                                                  | бэкенд, заглушка API   |
| `SESSION_SECRET`                | Ключ подписи cookie сессии                                                                                     | бэкенд                 |
| `LLM_API_KEY`, `LLM_MODEL`      | Ключ и модель LLM                                                                                              | бэкенд                 |
| `MODRINTH_USER_AGENT`           | `User-Agent` при выгрузке корпуса                                                                              | скрипты выгрузки       |
| `API_TARGET`                    | Адрес бэкенда для прокси Vite, например `http://localhost:8000`; если не задан, работает заглушка API (GAP-13) | интерфейс (разработка) |

### Вход при локальном запуске

Чтобы войти при локальной разработке, впишите в `.env` такие значения:

| Роль          | Переменные                                  | Логин и пароль      | Что откроется |
| ------------- | ------------------------------------------- | ------------------- | ------------- |
| Пользователь  | `USER_LOGIN=player`, `USER_PASSWORD=player` | `player` / `player` | экран поиска  |
| Администратор | `ADMIN_LOGIN=admin`, `ADMIN_PASSWORD=admin` | `admin` / `admin`   | админ-панель  |

Эти значения нужны только для локальной разработки и проверки макета. Для любого общего или публичного стенда задавайте другие логины и пароли (GAP-15).

## Запуск интерфейса

```bash
cp .env.example .env     # в корне репозитория, затем вписать значения из таблицы выше
cd code/frontend
npm install
npm run dev              # http://localhost:5173
```

Без `API_TARGET` `npm run dev` поднимает заглушку API (`code/frontend/dev-stub`): вход, поиск и счётчик работают на заготовленных ответах. Заглушка нужна только для разработки и проверки макета, в сборку она не входит.

Особые запросы заглушки для проверки состояний: `!пусто` — «Нет результатов», `!ошибка` — «Ошибка поиска», `!безответа` — «Результаты без объяснения».

Прочие команды:

```bash
npm run build            # сборка в code/frontend/dist
npm run typecheck        # проверка типов
npm test                 # тесты Vitest
```
