# 01. Архитектура

Статус: заготовка.

## Планируемый путь запроса

```
Интерфейс → API → предобработка запроса → поиск по индексу BM25 → топ-k документов → промпт → LLM → ответ в интерфейс
```

## Компоненты

| Компонент                                   | Назначение                               | Ответственный   |
| ------------------------------------------- | ---------------------------------------- | --------------- |
| Интерфейс (`code/frontend`)                 | Ввод задачи, показ результатов           | Верзаков Никита |
| Интеграция (`code/backend`)                 | API, связь интерфейса, поиска и LLM      | Прощаев Алексей |
| Поиск (`code/backend` или отдельный модуль) | Предобработка, индекс BM25, ранжирование | Кубанов Сергей  |
| Корпус (`code/data`)                        | Снимок описаний модов                    | Кубанов Сергей  |
