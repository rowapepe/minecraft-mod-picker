# Карта документов

| Раздел  | Назначение                                                                    | Индекс                                 |
| ------- | ----------------------------------------------------------------------------- | -------------------------------------- |
| Product | Поведение продукта: контекст, роли и сценарии, требования, интерфейс, правила | [Product/README.md](Product/README.md) |
| Tech    | Устройство приложения: архитектура, запуск, данные, API, проверки             | [Tech/README.md](Tech/README.md)       |
| Service | Решения и вопросы, источники, протокол проверок                               | [Service/README.md](Service/README.md) |

Список всех документов со статусами: [document-manifest.json](document-manifest.json).

Порядок работы над изменениями: сначала документ, потом код, потом проверка (см. `../AGENTS.md`).

Для крупной новой функции: папка `docs/Update/UPD-NNN-…/` с описанием изменения; после проверки основные документы Product и Tech обновляются, а пакет переносится в `Archive/Updates/`. Сейчас такой папки нет, она появится при первом содержательном изменении.
