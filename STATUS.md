## Сейчас

Бэкенд (`code/backend`, FastAPI) реализует контракт API: вход, проверка роли, аналитика в SQLite; `/api/search` отдаёт выдачу собственного BM25 по 1000 модам (`D-17`); запрос с кириллицей переводится через GigaChat (`D-18`, нужен `LLM_API_KEY`); объяснение LLM ещё не подключено. Интерфейс подключается к нему через `API_TARGET`.

Начата подготовка к КТ2: выгружен корпус из 1000 модов Modrinth (`code/data/mods.jsonl`), сделаны предобработка, собственный индекс BM25 (`code/search`) и benchmark поиска (Recall@5 = 0,567, MRR@5 = 0,775); дальше — ответы LLM для Accuracy и Correct Rejection Rate.

Подготовка к контрольной точке 1. Интерфейс из трёх экранов работает на заглушке API, добавлены продолжение и удаление чатов, расширенная аналитика с сохранением между перезапусками и автоматическим обновлением, общий переключатель темы.
