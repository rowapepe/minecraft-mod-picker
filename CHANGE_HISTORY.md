# История изменений

Каждому изменению присваивается идентификатор `CH-ГГГГ-ММ-ДД-NNN`. Записи идут от новых к старым.

## 2026-10-09

### CH-2026-10-09-003. Интерфейс перенесён в код, принят стек, документация приведена к дизайну

- **Что изменилось:**
  - **Код.** В `code/frontend` добавлен интерфейс на React, Vite и TypeScript: экран входа, экран поиска в виде чата (раздвижная боковая панель, список запросов сессии, поле ввода внизу, ответ выше) и админ-панель; защита экранов по роли; талисман «Зомби» с семью костюмами и скелет «Нет чатов». Добавлены тесты Vitest на выбор костюма и проверку запроса. Для разработки без бэкенда добавлена заглушка API `code/frontend/dev-stub`: она работает только в `npm run dev` и в сборку не входит;
  - **Настройки.** Все настройки собраны в один `.env` в корне репозитория; добавлен шаблон `.env.example` (имена без значений); Vite читает `.env` из корня;
  - **Product.** `04-interface-and-behavior` переписан под принятый дизайн (экраны, блоки, состояния, оформление, талисман, адаптивность); в `02-users-and-scenarios` добавлены `GWT-24…31`, в `03-requirements` — `REQ-23…28`, в `05-rules-and-data-meaning` — `RULE-UI-06…10`, группа `RULE-MASCOT-01…06`, разделы 2.10 (костюмы зомби) и 2.11 (запись сессии); обновлены `01-context` и `Product/README`. Идентификаторы существующих сценариев, требований и правил не менялись;
  - **Tech.** Заполнены `01-architecture` (стек, устройство интерфейса), `02-running` (настройки, вход при локальном запуске, запуск интерфейса), `04-api-and-access` (черновик контракта API вместо «аутентификации нет»), `05-verification`, `WORKSPACE_MAP`; в `03-data` добавлены рабочие допущения по формату корпуса и индекса;
  - **Service.** В `decisions.md` принято `D-08` (стек, закрывает `GAP-05`) и `D-09` (дизайн), добавлены открытые вопросы `GAP-13` (заглушка API), `GAP-14` (набор костюмов зомби), `GAP-15` (логины и пароли для локального запуска в документации); в `verification.md` записан протокол проверки макета; в `sources.md` добавлен раздел «Оформление» (шрифт Inter);
  - **Прочее.** Обновлены `README.md` (стек, запуск), `AGENTS.md` (раздел «Стек»), `document-manifest.json` (дата, статусы).
- **Почему:** подготовка к контрольной точке 1: готовый дизайн, перенесённый в работающий интерфейс, и документация, которая ему соответствует.
- **Влияние:**
  - проверка макета идёт по сценариям с этапом «макет»: `GWT-02…04`, `GWT-14…21`, `GWT-23…31`; все они выполнены (протокол в `docs/Service/verification.md`);
  - отправка запроса теперь по Enter, а не по Ctrl+Enter (`D-09`); Ctrl+Enter и Cmd+Enter тоже работают;
  - в основной области виден один запрос (`RULE-UI-05` сохранён), прежние запросы сессии лежат списком в боковой панели и живут до обновления страницы;
  - для входа при локальной разработке в документации указаны `player`/`player` и `admin`/`admin` (`GAP-15`);
  - в админ-панели оставлен блок «Возможные показатели» из трёх неактивных карточек до решения `GAP-12`;
  - части бэкенда и данных в стеке `D-08` ещё должны подтвердить Прощаев Алексей и Кубанов Сергей.
- **Открытые вопросы:** `GAP-13`, `GAP-14`, `GAP-15` и прежние, см. `docs/Service/decisions.md`.
